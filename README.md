# Template - BrandSystem

Dashboard que documenta las decisiones estructurales de un Brand System
(estrategia, fundamentos, componentes, templates y operación de marca).
Exportado originalmente desde [Figma Make](https://www.figma.com/design/i8FTndoqsyBd5GyaRme2nR/Template---BrandSystem).

Sitio publicado: https://valeriabydinamico.github.io/Template-BrandSystem/

## Correr el proyecto

```bash
npm install   # solo la primera vez
npm run dev   # http://localhost:5173
npm run build # build de producción en dist/
```

## Documentación del repo

| Archivo | Para qué |
|---|---|
| `GUIDELINES-DE-TRABAJO.md` | Reglas de trabajo: UI vs formato, tokens, completitud, cómo pasar contenido |
| `MANUAL-DE-FUNCIONALIDADES.md` | Qué hace cada herramienta del dashboard (Ajustes, Registro, Informe…) |
| `CLAUDE.md` | Guía técnica para sesiones de Claude Code: stack, estructura, estilado |
| `BRAND-SYSTEM-ARQUITECTURA.md` | Árbol de categorías y páginas del catálogo |
| `PENDIENTES.md` | Ideas anotadas para más adelante |
